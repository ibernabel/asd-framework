# Workflow: Domain Modeling

El usuario desea definir o actualizar la terminología de dominio del proyecto o registrar una decisión de arquitectura.

## Instrucciones para el Agente

1. Leer las instrucciones de la skill en `~/.agents/skills/domain-modeling/SKILL.md` o `.agents/skills/domain-modeling/SKILL.md`.
2. Revisar el código y `CONTEXT.md` actual.
3. Desafiar términos vagos y actualizar `CONTEXT.md` o crear un ADR en `docs/decisions/` según corresponda.
